# Embedded fonts

Subsets of Noto Sans / Serif / Sans Mono (SIL Open Font License 1.1) and
DejaVu Sans (Bitstream Vera / DejaVu license, symbols + Armenian + Georgian
fallback), generated by `tools/subset_fonts.sh`. Hinting and OpenType layout
tables are stripped; the kernel rasterizes outlines itself (src/web/font.c).
See LICENSE-Noto.txt and LICENSE-DejaVu.txt.
