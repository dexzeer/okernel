# Built-in adblocker for okai ("ablock") — EasyList + EasyPrivacy, always on

## Context

okai loads real sites with zero filtering: ads, trackers and ad iframes all fetch and render. The owner wants a built-in, non-negotiable, always-running adblocker that speaks the EasyList/uBlock filter syntax — the lists are data (CC-BY, attribution), the engine is ours, per the from-scratch rule. Decisions confirmed: ship **EasyList + EasyPrivacy** (static, refreshed at build), first milestone = **network blocking + cosmetic hiding**, no toggle/allowlist/UI.

Key facts from exploration that shape the design:
- `req_fetch()` (`src/okai.c:705`) is the single page-request choke point (documents, frames, CSS/img/script/XHR/fetch, media Range, preload-scanner). It sits **before** cache lookup, prefetch and `fetch_begin`, and its callers already turn any negative return into natural page-visible failure (`sub_fail` → error events at okai.c:2169-2173; `show_error` for main docs at okai.c:2063-2070). A block = one new return code `-3`.
- CSS atoms are **per-document** (`wdom.c` `d->atoms`), so a big pre-parsed hide stylesheet cannot be shared across documents. Instead (uBO's own architecture, adapted): index generic hide selectors by rightmost-compound *name hash* at boot; per document, walk the DOM, hash each element's class/id/tag/attr names, collect matching rules, and inject a **small per-document stylesheet**. The engine's rule index (`css_style.c:453+`, bucketed by class/id/tag atom) and selector support (incl. `:has()`, attribute substring) handle the rest; `display:none` reliably removes subtrees from style+layout.
- Data ships as a **second GRUB multiboot module** (the `lxroot.tar` pattern): `memory_boot_module(1,...)` (`src/memory.c:62`), pages PMM-reserved, read in place — zero-copy pattern strings.

## 2. `src/ablock.c` / `src/ablock.h` — the engine

**API:** `ablock_init()` (find module by cmdline `ablock` → start sliced parse), `ablock_parse_step(budget_us)` (returns 1 while more to do; idle-path template = `heap_pretouch`), `ablock_ready()`, `ablock_allows(url, top, kind)` → 1 allow / 0 block, `ablock_doc_css(struct wdoc* d, char** out)` → per-document hide CSS (kmalloc'd, ownership handed to the doc).

**Parse (single pass over module memory, sliced):** classify lines — comments/`[Adblock Plus 2.0]` header skipped; `@@` exceptions; `##`/`#@#` cosmetics; host-only rules (`||host^` with no wildcards → host hash set); network patterns. Options enforced in v1: `script,image,stylesheet,xmlhttprequest/xhr,font,subdocument/frame,document/main_frame,media,other`, `~`negations, `third-party/3p`, `first-party/1p`, `domain=/from=` (incl. `~`), `important`, `all`, `$badfilter` (post-pass drops matching pattern+options keys). Lines carrying v1-unsupported options (`redirect=`, `csp=`, `removeparam=`, `uritransform=`, `permissions=`, `popup`, `generichide/elemhide`, `$method=`) or `/regex/` patterns are **skipped and counted by reason** (fail-open, logged once at load). Patterns lowercased into one bump arena (kmalloc block); all index structures in kmalloc'd arrays, no per-filter kmalloc.

**Index:** token bucket table (uBO-style: pick longest non-generic alnum token per pattern, FNV-1a, 64k buckets, chaining) + small "no-token" list + host hash set. `$badfilter` dedup pass at end.

**Check (`ablock_allows`):** lowercase URL into a static buffer; untyped filters never match main documents (uBO semantics — EasyList `||host^` must not brick navigation), they do match frames and subresources. Order: host set → `$important` blocks → exceptions → blocks. Option prechecks (type set, 3p/1p via `site_tail` eTLD+1 approximation, domain list) before full anchored pattern match (`||` host-boundary anchor, `|` ends, `*`, `^` separator = non-alnum/`_%.-` or URL end; bounded iterative backtracking). Sub-µs typical.

**Cosmetic:** parse `dom1,~dom2##sel` / `#@#` unhide; procedural/uBO-only forms (`:has-text(`, `:style(`, `:matches-`, `-abp-`, `##^` HTML filters, `#$#`, `##+js`) skipped+counted. Generic rules name-hash indexed (rightmost compound's class/id/tag/attr name string); domain-qualified indexed by domain. `ablock_doc_css`: host + parent-domain lookup for domain rules, DOM walk (`wdom_next` like `collect_styles`) hashing element class/id/tag/attr names to gather candidates, unhide cancellation, emit `sel{display:none!important}` rules into a kmalloc buffer.

## 3. okai.c hooks (network)

- Top of `req_fetch()` (okai.c:705, after URL/host known): `ablock_allows(q->url, top, kind)` where kind maps `q->rk` (-1 → main doc vs iframe doc via `T->is_frame`; CSS/IMG/SCRIPT/REQ/FONT → stylesheet/image/script/xmlhttprequest/font). Blocked → `serial_printf("[ablk] block %s %s\n", kind_name(kind), url)` and return `-3`. Covers everything including redirects (`follow_redirect` → `req_reissue` → `req_fetch` re-check) and cache/prefetch (checked before them). Before ready: allow, log `[ablk] lists not ready` once.
- Existing caller behavior does the rest: subs → `sub_fail` (img error events, fetch() `TypeError('Failed to fetch')`, script error), preload (okai.c:828) → silently dropped and re-blocked on the real request, main tabs → `show_error` (terse). DoH and `mplay` bypass `req_fetch` and stay unfiltered (correct).

## 4. wdoc.c/wjs.c hooks (cosmetic)

- `struct wdoc` tail fields: `char* ablock_css; int ablock_dirty;`. New static helper `ablock_sheet_add(d)` in wdoc.c: builds text via `ablock_doc_css`, `add_sheet_ordered(d, css, len, 0, 0x7F000000, 0, 0)` (sorts last; `!important` wins). Called in `wdoc_load` (wdoc.c ~812, after `collect_styles`, before first paint → no flash) and again in `rebuild_styles` (wdoc.c:780) since script-touched `<style>`/`<link>` rebuild the set from scratch.
- Mutations: the C-side DOM mutators (`wjs_inserted/removed/attr_changed`, wjs.c:1312-1362) set `d->ablock_dirty = 1`; coalesced rebuild (min interval ~200 ms) in the `wdoc_update`/paint path sets `style_dirty` after re-adding the sheet. Late-inserted ad nodes get hidden like uBO.

## 5. desktop.c wiring

`ablock_init()` right after `okai_init()` (desktop.c:2029); `ablock_parse_step()` pumped in the main-loop idle branch next to `heap_pretouch` (desktop.c:3256 area). Load summary line: `[ablk] N filters (M host, K network, J cosmetic), X skipped, Y ms, Z KB`.

## 6. Tests

- **Host unit test** `tests/test_ablock.c` via `host-tests` (plain `gcc -m32 -Isrc` build of `ablock.c` with a stubbed module source): real EasyList excerpts + synthetic lines; assert match/no-match for anchors, `^`, `*`, exceptions, `important`, `badfilter`, type/3p/domain options, untyped-vs-document, cosmetic extraction (generic vs domain-qualified, unhide).
- **Headless** `tests/headless/test_ablock.py` (okvm pattern, own port): `make desktop ABLOCK_EXTRA=tests/headless/ablock_test.txt`; local HTTP server with hit counters (test_okai_cache.py style). Page loads `/ok.js`, `/ad.js`, `/banner.png`, XHR `/track.gif`, `<div class="ad-banner">`. Assert: server never receives ad hits, control `/ok.js` arrives, serial shows `[ablk] block` lines + load summary, no `PAGE FAULT`/`[ISR]`/`kmalloc FAIL`, screenshot shows the div hidden (fixed-layout page, pixel check on the PPM).
- **Regression:** `test_nav.py`, `test_okai_page.py`, `test_okai_js.py`, `test_okai_frames.py`, `test_okai_media.py`, `test_sites.py` (real HTTPS sites must still work with filtering on). **Perf sanity:** page-load timeline (`tests/headless/perf_load.py` or `perf_win.ps1`) before/after on one heavy page.
